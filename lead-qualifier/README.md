# Кваліфікація лідів

Скіл `lead-qualifier` · етап воркшопу «Шлях клієнта до першої оплати»
Автор методики: Віталій Матвєєв

## Що робить

Веде базу лідів, оцінює кожного за бюджетом, тим, хто вирішує, гостротою потреби і термінами (0–12 балів), ставить пріоритет A/B/C, знаходить загублених лідів і пише повторні повідомлення. Тримає ритм нагадувань.

## Як запустити

**Claude Code**
```bash
mkdir -p ~/.claude/skills && cp -r lead-qualifier ~/.claude/skills/
```

**Codex**
```bash
mkdir -p ~/.codex/skills && cp -r lead-qualifier ~/.codex/skills/
```
Якщо ваша версія Codex ще не бачить скіли — додайте вміст `SKILL.md` у `AGENTS.md` у папці проєкту.

**Gemini CLI** — додайте вміст `SKILL.md` у `GEMINI.md` у папці проєкту.

**Будь-який чат** (Claude, ChatGPT, Gemini) — скопіюйте текст `SKILL.md` нижче рядка `---` після опису і вставте першим повідомленням.

## Приклади запитів

- «Ось наші ліди — кому дзвонити першим?»
- «Хто з лідів загубився між етапами?»
- «Напиши повторні повідомлення тим, хто не відповів після демо»

## Важливо

Скіл рахує, тренує і розбирає, але не працює замість вас. Висновки про ринок — тільки з реальних розмов із клієнтами.

# GTM-скіли для команд акселератора

Автор: Віталій Матвєєв · instagram.com/matvieiev.vitaliy

Шість AI-скілів для практики після воркшопу «Customer Validation & Go-to-Market». Кожен відповідає етапу воркшопу і працює на одну ціль: перші платні клієнти до demo day.

| Скіл | Етап воркшопу | Що робить |
|---|---|---|
| **funnel-from-end** | Ціль і воронка від кінця | Рахує воронку від цілі demo day до тижневого плану лідів, дзвінків і пропозицій, знаходить найслабший етап |
| **offer-builder** | Стан А і бажаний стан | Розкладає стан клієнта, рахує вартість проблеми, визначає рівень обізнаності, пише оффер одним реченням, заголовок лендингу і перший слайд демо |
| **discovery-trainer** | Discovery-дзвінок і демо | Готує питання під ICP, грає клієнта для репетиції, розбирає репетицію або транскрипт реального дзвінка |
| **channel-sprint** | 40 каналів → топ 3–5 → 1 | Генерує до 40 каналів, звужує до 3–5, складає тест на тиждень з метрикою, розбирає результати тесту |
| **lead-qualifier** | Шлях клієнта до оплати | Веде базу лідів, оцінює кожного (бюджет, хто вирішує, гострота, терміни), каже, кому дзвонити першим, пише повторні повідомлення |
| **gtm-manifesto** | GTM-маніфест | Збирає маніфест із 6 пунктів, перевіряє на типові помилки, оновлює після кожних 10 розмов |

Скіл не працює замість вас. Він рахує, тренує і розбирає. Шукати клієнтів, писати їм і дзвонити — ваша робота. Висновки про ринок — тільки з реальних розмов.

## Встановлення

Кожен скіл — це папка з файлом `SKILL.md`. Скопіюйте всі шість папок у потрібне місце.

### Claude Code

```bash
mkdir -p ~/.claude/skills
cp -r funnel-from-end offer-builder discovery-trainer channel-sprint lead-qualifier gtm-manifesto ~/.claude/skills/
```

Перезапустіть Claude Code і просто пишіть запит: «Порахуй нашу воронку до demo day», «Сформулюй наш оффер», «Порепетируй зі мною discovery-дзвінок», «Склади тест каналів», «Кому з лідів дзвонити першим», «Збери наш GTM-маніфест».

### Codex

```bash
mkdir -p ~/.codex/skills
cp -r funnel-from-end offer-builder discovery-trainer channel-sprint lead-qualifier gtm-manifesto ~/.codex/skills/
```

Перезапустіть Codex і пишіть запит так само. Якщо ваша версія Codex ще не бачить скіли — додайте вміст потрібного `SKILL.md` у файл `AGENTS.md` у папці проєкту.

### Gemini CLI

Додайте вміст потрібного `SKILL.md` у файл `GEMINI.md` у папці проєкту (або в `~/.gemini/GEMINI.md`, щоб працювало всюди), і пишіть запит.

### Будь-який чат (Claude, ChatGPT, Gemini у браузері)

Відкрийте `SKILL.md`, скопіюйте все нижче рядка `---` після опису і вставте першим повідомленням або в інструкції проєкту.

## Порядок роботи на 2 тижні

1. **funnel-from-end** — зафіксуйте ціль demo day і тижневий план.
2. **offer-builder** — стан А, вартість проблеми, оффер одним реченням.
3. **channel-sprint** — 40 каналів → 3–5 тестів на тиждень з метрикою до старту.
4. **discovery-trainer** — підготовка питань і 2–3 репетиції, потім 10 реальних дзвінків; транскрипт кожного — у режим «Розбір».
5. **lead-qualifier** — щодня: кому дзвонити, хто загубився, які повторні повідомлення надіслати.
6. **gtm-manifesto** — зберіть маніфест після воркшопу і оновіть після 10 розмов.
7. Щотижня оновлюйте цифри у **funnel-from-end** і результати тестів у **channel-sprint**.

Результати додавайте на дошку воркшопу, у колонку своєї команди.

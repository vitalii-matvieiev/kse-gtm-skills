# Тренажер дзвінка з клієнтом

Скіл `discovery-trainer` · етап воркшопу «Discovery-дзвінок і демо»
Автор методики: Віталій Матвєєв

## Що робить

Три режими: готує питання під вашого ідеального клієнта, грає скептичного клієнта для репетиції (стоп-слово «стоп») і розбирає розмову — репетицію або транскрипт реального дзвінка — за чеклістом із 8 пунктів. Заповнює запис у базу дзвінків.

## Як запустити

**Claude Code**
```bash
mkdir -p ~/.claude/skills && cp -r discovery-trainer ~/.claude/skills/
```

**Codex**
```bash
mkdir -p ~/.codex/skills && cp -r discovery-trainer ~/.codex/skills/
```
Якщо ваша версія Codex ще не бачить скіли — додайте вміст `SKILL.md` у `AGENTS.md` у папці проєкту.

**Gemini CLI** — додайте вміст `SKILL.md` у `GEMINI.md` у папці проєкту.

**Будь-який чат** (Claude, ChatGPT, Gemini) — скопіюйте текст `SKILL.md` нижче рядка `---` після опису і вставте першим повідомленням.

## Приклади запитів

- «Підготуй питання для дзвінка з власником клініки»
- «Зіграй клієнта, я проведу дзвінок»
- «Розбери транскрипт мого дзвінка»

## Важливо

Скіл рахує, тренує і розбирає, але не працює замість вас. Висновки про ринок — тільки з реальних розмов із клієнтами.

# Оффер від стану клієнта

Скіл `offer-builder` · етап воркшопу «Стан А і бажаний стан»
Автор методики: Віталій Матвєєв

## Що робить

Розкладає, як клієнт живе зараз (стан А), рахує вартість проблеми в годинах і гривнях, формулює бажаний стан словами клієнта, визначає рівень обізнаності і пише оффер одним реченням у 3 варіантах. Додає заголовок лендингу, перший слайд демо і перше повідомлення клієнту.

## Як запустити

**Claude Code**
```bash
mkdir -p ~/.claude/skills && cp -r offer-builder ~/.claude/skills/
```

**Codex**
```bash
mkdir -p ~/.codex/skills && cp -r offer-builder ~/.codex/skills/
```
Якщо ваша версія Codex ще не бачить скіли — додайте вміст `SKILL.md` у `AGENTS.md` у папці проєкту.

**Gemini CLI** — додайте вміст `SKILL.md` у `GEMINI.md` у папці проєкту.

**Будь-який чат** (Claude, ChatGPT, Gemini) — скопіюйте текст `SKILL.md` нижче рядка `---` після опису і вставте першим повідомленням.

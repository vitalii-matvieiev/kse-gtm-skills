# GTM-маніфест

Скіл `gtm-manifesto` · етап воркшопу «GTM-маніфест команди»
Автор методики: Віталій Матвєєв

## Що робить

Збирає план виходу на ринок на один аркуш: ідеальний клієнт, цінність, ціна, як доставляємо цінність, канали, як клієнт платить. Перевіряє на типові помилки і після кожних 10 розмов оновлює у форматі «було → стало».

## Як запустити

**Claude Code**
```bash
mkdir -p ~/.claude/skills && cp -r gtm-manifesto ~/.claude/skills/
```

**Codex**
```bash
mkdir -p ~/.codex/skills && cp -r gtm-manifesto ~/.codex/skills/
```
Якщо ваша версія Codex ще не бачить скіли — додайте вміст `SKILL.md` у `AGENTS.md` у папці проєкту.

**Gemini CLI** — додайте вміст `SKILL.md` у `GEMINI.md` у папці проєкту.

**Будь-який чат** (Claude, ChatGPT, Gemini) — скопіюйте текст `SKILL.md` нижче рядка `---` після опису і вставте першим повідомленням.

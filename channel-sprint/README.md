# Канали: 40 → 3–5 → 1

Скіл `channel-sprint` · етап воркшопу «40 каналів і топ 3–5»
Автор методики: Віталій Матвєєв · instagram.com/matvieiev.vitaliy

## Що робить

Генерує до 40 конкретних каналів під вашого клієнта, звужує до 3–5 за чотирма критеріями, складає тест на тиждень для кожного (гіпотеза, дія, відповідальний, бюджет, метрика успіху до старту). Після тижня рахує вартість одного дзвінка і каже: масштабувати, покращувати чи закривати.

## Як запустити

**Claude Code**
```bash
mkdir -p ~/.claude/skills && cp -r channel-sprint ~/.claude/skills/
```

**Codex**
```bash
mkdir -p ~/.codex/skills && cp -r channel-sprint ~/.codex/skills/
```
Якщо ваша версія Codex ще не бачить скіли — додайте вміст `SKILL.md` у `AGENTS.md` у папці проєкту.

**Gemini CLI** — додайте вміст `SKILL.md` у `GEMINI.md` у папці проєкту.

**Будь-який чат** (Claude, ChatGPT, Gemini) — скопіюйте текст `SKILL.md` нижче рядка `---` після опису і вставте першим повідомленням.

## Приклади запитів

- «Де шукати наших клієнтів? Дай 40 каналів»
- «Склади тест 3 каналів на тиждень»
- «Ось результати тесту — що масштабуємо?»

## Важливо

Скіл рахує, тренує і розбирає, але не працює замість вас. Висновки про ринок — тільки з реальних розмов із клієнтами.

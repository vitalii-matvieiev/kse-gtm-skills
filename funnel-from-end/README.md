# Воронка від кінця

Скіл `funnel-from-end` · етап воркшопу «Ціль і воронка від кінця»
Автор методики: Віталій Матвєєв

## Що робить

Рахує, скільки лідів, контактів, демо і пропозицій потрібно щотижня, щоб вийти на ціль demo day. Три сценарії: песимістичний, нормальний, хороший. Якщо є фактичні цифри — знаходить найслабший етап воронки.

## Як запустити

**Claude Code**
```bash
mkdir -p ~/.claude/skills && cp -r funnel-from-end ~/.claude/skills/
```

**Codex**
```bash
mkdir -p ~/.codex/skills && cp -r funnel-from-end ~/.codex/skills/
```
Якщо ваша версія Codex ще не бачить скіли — додайте вміст `SKILL.md` у `AGENTS.md` у папці проєкту.

**Gemini CLI** — додайте вміст `SKILL.md` у `GEMINI.md` у папці проєкту.

**Будь-який чат** (Claude, ChatGPT, Gemini) — скопіюйте текст `SKILL.md` нижче рядка `---` після опису і вставте першим повідомленням.

## Приклади запитів

- «Порахуй нашу воронку до demo day»
- «Скільки лідів на тиждень нам потрібно для 5 платних клієнтів?»
- «Ось наші цифри за 2 тижні — де ламається воронка?»

## Важливо

Скіл рахує, тренує і розбирає, але не працює замість вас. Висновки про ринок — тільки з реальних розмов із клієнтами.
